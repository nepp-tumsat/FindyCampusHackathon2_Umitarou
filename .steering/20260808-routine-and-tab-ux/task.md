# 定例自動化＋タブ型UXへの刷新

## やること
UI/UX監査（docs/product.md）で出たギャップを解消する。

1. **定例リマインド（routine）**：Agents SDKのschedule機能で、登録したタイミングに連絡下書きを自動生成して積む。確定は人間（Human-in-the-loop維持）
2. **コピーボタン**：下書き・確定済み文面をワンクリックでクリップボードへ
3. **参照した振り返りの可視化**：下書きカードに「この生成が参照した振り返り」を表示し、PDCAの環が画面で見えるように
4. **タブ型UXへ置き換え**：1枚の縦長ページをやめ、「連絡／記憶／定例／掲示板」の4タブに再編。記憶タブに宛先の書き方メモ編集とメンバーを集約
5. **全般ノートの置き場**：常設プロジェクト「サークル全般」をシードして解決
