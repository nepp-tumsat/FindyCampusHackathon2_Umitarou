# 相談コア化・メンバー格上げ・返信スレッド

## やること
- さくるんを連絡特化から「困りごとの相談窓口」に転換する（相談タブ・初期表示）
- メンバーを編集可能な記憶に格上げし、モチベーション向上の軸を実装で支える
- 確定後の行き止まりを解消（相手の返信を貼ると返事の下書きが作れる）

## タスクリスト
- [x] 型：ChatMessage/DraftSuggestion、Memberにmemo、Draftにreply系フィールド追加
- [x] エージェント：consult（記憶全体を注入した相談＋下書き提案）、chat履歴保持
- [x] エージェント：replyDraft（送信済み文面＋相手の返信を文脈に返事を生成）
- [x] エージェント：メンバーをstate化、updateMemberMemo、宛先解決にメンバー個人（member:mX）を追加
- [x] UI：相談タブ（チャット風・提案ボタン→下書きタブへ）、返信フォーム、メンバーメモ編集
- [x] docs：product.md（相談コア・当事者意識の軸、並行エージェントで更新）、architecture.md
- [x] 動作確認：相談→提案→高橋くん個人宛の声かけ文（本人のメモを汲んだ内容）まで一気通貫を確認

## 完了条件
- 「高橋くん最近来てないんだよね」の相談に、メンバーメモを踏まえた助言＋声かけ文の提案が返り、ボタンから本人宛の下書きができる
- 確定済みの下書きに相手の返信を貼ると、やり取りを踏まえた返事の下書きが作られる
- `npm run build`が通る
